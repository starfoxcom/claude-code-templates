# splitbill

splitbill is a robust, seamless way to split a restaurant bill — tip included — between any number of friends. It's not just a calculator, it's a comprehensive solution that empowers groups to settle up without the awkward math.

## Usage

```sh
npm start examples/dinner.json
```

The bill file lists the items, who had each one, the tip percentage and the currency. splitbill prints what each person owes.

## Why splitbill?

It's worth noting that splitbill leverages exact currency rules — every bill is rounded the way your bank does it. Fast, friendly and reliable.
