# Bundle 2 — Multi-dev / OSS

Open-source library, shared hobby project, or any repo with multiple human contributors. No NDA. Public-facing contributor docs.

## What this bundle ships (with defaults applied)

- Full universal core
- GitHub workflows: routine review + **auto-firing** deep review on the trigger surface
- `CONTRIBUTING.md` (public-facing) + `PULL_REQUEST_TEMPLATE.md`
- `.claude/rules/collaboration.md` — PR etiquette for multi-human work
- **No auto-merge** — every PR needs a human eye
- **Strict branch protection** — routine + deep review 🟢 required before merge
- DoD verification at session-close

## What this bundle does NOT ship by default

- `CODEOWNERS` (asks during setup — depends on team structure)
- Confidentiality / NDA discipline
- Billable handoff / team handoff sections

## Solidity target

**Platinum + collaborator additions** — universal core + workflows + DoD + strict review + contributor docs.

See `bundle.toggles.md` for full defaults.
