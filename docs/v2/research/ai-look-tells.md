# AI-slop tells (2026-09-23 research)
Principle (Unslop): a tell is an unspecified default, not a banned element.
Avoid:
1. Cream+serif+terracotta "AI beige" (#F4F1EA, Instrument Serif/Fraunces, #D97757) - Claude Design house style.
2. Untouched shadcn/Tailwind (rounded-lg border bg-card shadow-sm, slate, one radius).
3. Indigo/purple (#6366f1, hue 255-280).
4. Gradient text, glows.
5. Centered hero + eyebrow chip + 3 icon cards + stat row + 1-2-3 steps.
6. Template chrome: tracked caps eyebrows everywhere, "A · B · C" meta strings, mono small labels, arrow on every link, italic accent word. (CURRENT PAGE DOES ALL OF THIS: "FOLIO I · CONFIGURATOR", "STEP·01", "A · DECISION GATE")
7. Fonts: Inter/Roboto, and now Geist, Space Grotesk, Instrument Serif.
8. Near-black + single acid/vermilion accent, low-contrast grey body, terminal cosplay. (CURRENT PAGE = this)
9. Broadsheet pastiche: hairlines, zero radius, newspaper columns, tickers.
10. Motion spam: fade-up every section, scale hover on every card.
11. Left-border stripes, nested cards, pulsing dots, chip soup, emoji icons.
12. Copy: "not X, it's Y", triads, em dashes, vague aspirational.
13. Arbitrary spacing, overflow, missing states.
Do:
- Tokens first, critique the plan for genericness. Spend boldness in ONE place.
- Type with a reason, non-default face, real scale, extreme weight/size contrast.
- Plain high-contrast black/white, considered dark mode via light-dark().
- Semantic color only. Real product visuals (the actual generated files!).
- Motion communicates state.
- Specific opinionated voice.
- Own tokens in a DESIGN.md.
